# Инструкция по установке и использованию — День 6

Проект состоит из двух процессов: **бэкенд** FastAPI (порт `8000`) и
**фронтенд** Streamlit (порт `8501`). Агенты и их история живут в памяти
бэкенда.

## 1. Установка зависимостей

Нужен Python 3.10+ (разрабатывалось на 3.14). Все команды — из папки `day6/`.

```bash
cd day6
python -m venv .venv                       # Windows
# python3 -m venv .venv                    # Linux/macOS
.venv/Scripts/python -m pip install -r requirements.txt   # Windows
# .venv/bin/python -m pip install -r requirements.txt     # Linux/macOS
```

Проверка установки:

```bash
.venv/Scripts/python -c "import fastapi, uvicorn, streamlit, openai, requests; print('ok')"
```

## 2. Переменные окружения: ключ DeepSeek

Ключ читает только **бэкенд** (фронтенду он не нужен). Порядок поиска:
`day6/.env` → переменная окружения `DEEPSEEK_API_KEY`.

Способ 1 — файл `day6/.env` (рекомендуется; `.env` в git не попадает):

```bash
copy .env.example .env        # Windows
# cp .env.example .env        # Linux/macOS
```

Затем отредактируйте `day6/.env`: подставьте реальный ключ вместо
`вставьте-сюда-ваш-ключ`:

```
DEEPSEEK_API_KEY=sk-...
```

Способ 2 — переменная окружения:

```powershell
# PowerShell
$env:DEEPSEEK_API_KEY = "sk-..."
```

```bash
# bash
export DEEPSEEK_API_KEY="sk-..."
```

> Без ключа приложение работает, но генерация возвращает понятную ошибку 502
> «Ключ API не задан» (создание/список/удаление/история — без ограничений).

## 3. Запуск

Терминал 1 — бэкенд (из папки `day6/`):

```bash
.venv/Scripts/python -m uvicorn backend.main:app --port 8000
```

Проверка: <http://127.0.0.1:8000/docs> (Swagger) или
`curl.exe http://127.0.0.1:8000/agents` → `[]`.

Терминал 2 — фронтенд (из папки `day6/`):

```bash
.venv/Scripts/python -m streamlit run app.py
```

Откройте <http://localhost:8501>. Если бэкенд запущен на другом адресе —
задайте переменную окружения `DAY6_BACKEND_URL` перед запуском фронтенда
(по умолчанию `http://127.0.0.1:8000`).

## 4. Сценарии использования

### 4.1. Создать агента в интерфейсе

1. В боковой панели заполните форму «Новый агент» (имя, модель, температура,
   системный промпт, max_tokens) и нажмите «Создать агента».
2. Агент появится в списке и станет активным.

### 4.2. Создать агента через API (curl)

```bash
curl.exe -X POST http://127.0.0.1:8000/agents -H "Content-Type: application/json" ^
  -d "{\"name\":\"Конспектёр\",\"temperature\":0.3,
       \"system_prompt\":\"Излагай тезисами.\"}"
```

В ответе — `agent_id`, сохраните его для следующих шагов (далее `<ID>`).

### 4.3. Отправить запрос

Через интерфейс: выберите агента, введите запрос, нажмите «🚀 Отправить
запрос» — увидите ответ, время, токены и `finish_reason`.

Через API:

```bash
curl.exe -X POST http://127.0.0.1:8000/agents/<ID>/generate ^
  -H "Content-Type: application/json" ^
  -d "{\"prompt\":\"Что такое RAG?\"}"
```

Успех — `200` с ответом и метаданными; ошибка (нет ключа, DeepSeek недоступен)
— `502` со `status: "error"` и понятным `error`.

### 4.4. Посмотреть историю

Через интерфейс — раздел «🗂 История запросов» (последние 20). Через API:

```bash
curl.exe http://127.0.0.1:8000/agents/<ID>/history
```

История включает и успешные попытки, и ошибки (новые первыми).

### 4.5. Удалить агента

Кнопка «🗑 Удалить» рядом с активным агентом или
`curl.exe -X DELETE http://127.0.0.1:8000/agents/<ID>`.

### 4.6. Массовое создание — «спавн» десятков/сотни агентов

1. В боковой панели выберите количество (10–100) и нажмите
   «Заспавнить N агентов».
2. Каждый агент получает **свои** параметры: имена `agent-0001…`, модель
   (каждый 10-й — `deepseek-reasoner`), температуру (цикл по сетке 0.2–1.7),
   системный промпт (ротация 4 ролей), `max_tokens` (1024/2048/4096).

Создание экземпляров не обращается к DeepSeek, поэтому 100 агентов создаются
мгновенно — это и есть демонстрация масштабируемости менеджера-синглтона
(подробности в `architecture.md`). Эквивалент в API — 100 вызовов `POST /agents`
с разными телами.

## 5. FAQ и возможные проблемы

| Проблема | Решение |
| --- | --- |
| Фронтенд пишет «Бэкенд недоступен» | Запустите uvicorn (раздел 3), нажмите «🔄 Обновить список». `requests` не ходит через браузер, CORS не при чём. |
| «Порт 8000 занят» | Найдите и остановите процесс или смените порт: `--port 8001` у uvicorn и `DAY6_BACKEND_URL=http://127.0.0.1:8001` у фронтенда. |
| Генерация: «Ключ API не задан» (502) | Создайте `day6/.env` или задайте `DEEPSEEK_API_KEY` (раздел 2). Ключ читается на каждый запрос — рестарт не нужен. |
| DeepSeek отвечает ошибкой/таймаутом | Проверьте сеть и лимиты аккаунта (429). Ошибка показана в UI, агент и сервер продолжают работать. |
| После рестарта бэкенда агенты пропали | Это нормально: состояние в памяти. Для постоянного хранения нужна БД (вне скоупа дня 6, см. architecture.md). |
| `deepseek-reasoner` игнорирует температуру | Поведение провайдера: модель рассчитана на reasoning. Используйте `deepseek-chat`, если важна температура. |
