# RULES.md — sticky-правила дня 21

Sticky-правила omp читает только из native-локаций (`.omp/RULES.md`): корневой
`RULES.md` — читаемая копия для людей, проектные правила — корневые `AGENTS.md`,
`RULES.md` и `docs/project-rules.md`.

Работаем только с файлами в `day21/`. Папки `day1`–`day20` — архив: не читать и не упоминать.
Все новые изменения вносить только в `day21/`. Не создавать новые папки `dayN`.
Состояние дня фиксировать git-коммитом и тегом `dayN`.
Документация описывает только текущее состояние проекта: устаревшее удалять, не копировать.
День не закрывается без обновления `docs/usage.md`: обязателен раздел с инструкцией по запуску новой функциональности (команды, кнопки, скрипты).
Тесты не дублировать — обновлять существующие.
Сложные задания проходят через `ARCHITECT_PROMPT.md` перед выполнением. Простые задачи можно выполнять напрямую.
Перед началом работы убедиться, что рабочая директория чистая (`git status`).
Всегда `read` вместо `cat`/`head`/`tail`, `grep`/`glob` вместо `bash grep`/`find`.
Тяжёлые задачи (индексация, сводки, пакетная обработка) — в непиковые часы DeepSeek (`prefer_off_peak`) или на локальную модель (Ollama).
