# AGENTS.md — день 21 (основная папка проекта)

Правила работы в этом каталоге. Устройство дня — [`STRUCTURE.md`](STRUCTURE.md),
инструкция — [`docs/usage.md`](docs/usage.md), sticky-правила —
[`.omp/RULES.md`](.omp/RULES.md), скиллы проекта — в `.agents/skills/`.

## Границы

- **Основная папка — `day21`.** Папки `day1`–`day20` — архивные снимки: не читать
  и не упоминать при работе. Они исключены из обхода поиска корневым
  `.gitignore` (omp `grep`/`glob`/`find` уважают его) и перечислены в
  `.clineignore`.
- **Не создавать новые папки `dayN`.** Состояние дня фиксируется git-коммитом и
  тегом `dayN`.
- **Все изменения — только в `day21/`** (плюс корневые `CHANGELOG.md` и
  `AGENTS.md`, если запись относится к дню).

## Документация и тесты

- Документация описывает **только текущее состояние** проекта: устаревшие
  сценарии удалять, не копировать из прошлых дней.
- Тесты не дублировать. Изменение функциональности отражать в **существующих**
  тестах; новый файл — только для новой сущности.
- Обязательная проверка перед коммитом — `uv run pytest` из `day21/`; лимиты
  строк — скилл `fastapi-streamlit-day-structure` (любой `.py` ≤ 400,
  `app.py` ≤ 100, `backend/api/main.py` ≤ 80).

## Инструменты

- Всегда `read` вместо `cat`/`head`/`tail`; `grep`/`glob` вместо `bash grep`/
  `find`/`ls`; `edit` вместо `sed -i` (включён `bashInterceptor`).
- Тяжёлые задачи (индексация, генерация сводок, пакетная обработка) планировать
  на **непиковые часы DeepSeek** — флаг `prefer_off_peak`,
  [`backend/domain/peak_hours.py`](backend/domain/peak_hours.py).

## Рабочий процесс нового дня

1. Убедиться, что `git status` чистый.
2. Реализовать функциональность дня в `day21/`.
3. Обновить документацию (только текущее состояние): `README.md`,
   `STRUCTURE.md`, `docs/`.
4. Обновить или добавить тесты (не дублировать существующие).
5. Запустить `uv run pytest`.
6. Закоммитить с сообщением `dayN: краткое описание`.
7. Поставить git-тег `dayN`.
8. Создать отчёт в `day21/docs/reports/`, если он нужен заданию.

## Экономия контекста

Действующие механизмы и их настройки: `bashInterceptor`, плагин
`@mxalbert/context-mode`, расширение `billion-context`, встроенный
`compaction` (включая `idleEnabled`), исключение архива из поиска. Замеры —
[`docs/reports/context_optimization.md`](docs/reports/context_optimization.md).
