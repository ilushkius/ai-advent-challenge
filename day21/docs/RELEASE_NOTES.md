# Релиз 1.1.0 — 2026-10-16

Итог 35-дневного челленджа ai-challenge: агентная система с RAG, MCP и ассистентами.

## Ключевые изменения
- Правила проекта: миграция с Cline + OpenSpec + Superpowers + Caveman на omp.sh
- day34: файловый ассистент с MCP file_server, планированием по цели, dry_run и реальными файловыми операциями
- day33: ассистент поддержки с RAG по FAQ и MCP для пользователей и тикетов
- day32: автоматизированный пайплайн AI-ревью кода с GitHub Action, MCP и RAG
- day32: режим ревью GitHub PR с авто-получением диффа и публикацией комментариев

## Как обновиться
1. `git pull`, затем `uv sync` в папке `day21/`.
2. `uv run pytest -m "not slow"` — убедиться, что тесты проходят.
3. `DEEPSEEK_API_KEY` — в `day21/.env` (образец — `day21/.env.example`).
4. Локальная модель необязательна: `ollama serve` и `LLM_PROVIDER=local`.
