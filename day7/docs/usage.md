# Инструкция по установке и использованию — День 7

Проект состоит из двух процессов: **бэкенд** FastAPI (порт `8000`) и
**фронтенд** Streamlit (порт `8501`). Диалоги агентов хранятся в SQLite
(`day7/agents.db`) на бэкенде и **переживают его перезапуск**.

## 1. Установка зависимостей

Нужен Python 3.10+ (разрабатывалось на 3.14). Все команды — из папки `day7/`.

```bash
cd day7
python -m venv .venv                       # Windows
# python3 -m venv .venv                    # Linux/macOS
.venv/Scripts/python -m pip install -r requirements.txt   # Windows
# .venv/bin/python -m pip install -r requirements.txt     # Linux/macOS
```

Проверка установки:

```bash
.venv/Scripts/python -c "import fastapi, uvicorn, streamlit, openai, requests, sqlalchemy; print('ok')"
```

## 2. Переменные окружения: ключ DeepSeek

Ключ читает только **бэкенд** (фронтенду он не нужен). Порядок поиска:
`day7/.env` → переменная окружения `DEEPSEEK_API_KEY`.

Способ 1 — файл `day7/.env` (рекомендуется; `.env` в git не попадает):

```bash
copy .env.example .env        # Windows
# cp .env.example .env        # Linux/macOS
```

Затем отредактируйте `day7/.env`: подставьте реальный ключ вместо
`вставьте-сюда-ваш-ключ`:

```
DEEPSEEK_API_KEY=sk-...
```

Способ 2 — переменная окружения:

```powershell
# PowerShell
$env:DEEPSEEK_API_KEY = "sk-..."
```

> Без ключа приложение работает: создание/список/удаление/очистка истории — без
> ограничений; генерация возвращает понятную ошибку 502 «Ключ API не задан».

## 3. Запуск

Терминал 1 — бэкенд (из папки `day7/`): при старте создаётся `agents.db` и
восстанавливаются агенты с историей.

```bash
.venv/Scripts/python -m uvicorn backend.main:app --port 8000
```

Проверка: <http://127.0.0.1:8000/docs> (Swagger) или
`curl.exe http://127.0.0.1:8000/agents` → `[]`.

Терминал 2 — фронтенд (из папки `day7/`):

```bash
.venv/Scripts/python -m streamlit run app.py
```

Откройте <http://localhost:8501>. Если бэкенд на другом адресе — задайте
`DAY7_BACKEND_URL` перед запуском фронтенда (по умолчанию
`http://127.0.0.1:8000`).

## 4. Сценарии использования

### 4.1. Создать агента

В боковой панели заполните форму «➕ Новый агент» (имя, модель, температура,
системный промпт, max_tokens) и нажмите «Создать агента». Агент появится в
списке с подписью `имя · модель · N сообщений` (у нового — 0).

Через API: `curl.exe -X POST http://127.0.0.1:8000/agents -H
"Content-Type: application/json" -d "{\"name\":\"Конспектёр\"}"` → в ответе
`agent_id` (далее `<ID>`).

### 4.2. Вести чат

Выберите агента в списке и пишите сообщения внизу → «🚀 Отправить». Каждое
сообщение показывается в чате с ролью («🧑 Вы» / «🤖 Ассистент») и добавляется в
историю агента. Следующий ответ модели строится по **всему** диалогу — агент
помнит, о чём говорили ранее.

### 4.3. Очистить историю

Кнопка «🧹 Очистить историю» удаляет диалог агента из SQLite (`DELETE
/agents/{id}/history`). Агент и его конфигурация остаются; новый диалог
начинается с нуля.

### 4.4. Демонстрация «диалог переживает рестарт» (для видео)

1. Запустите бэкенд и фронтенд, создайте агента и напишите 3–4 сообщения.
2. Покажите историю в интерфейсе и в SQLite (п. 4.5).
3. Остановите бэкенд (Ctrl+C).
4. Запустите бэкенд снова: `uvicorn backend.main:app --port 8000`.
5. Обновите страницу фронтенда и продолжите диалог — агент помнит предыдущие
   сообщения и отвечает с учётом контекста.

### 4.5. Просмотр SQLite

Покажите содержимое базы (Python встроен — отдельный `sqlite3` не нужен), из
папки `day7/`:

```bash
python -c "import sqlite3; con = sqlite3.connect('agents.db'); \
print('AGENTS:'); [print(' ', r) for r in con.execute('select agent_id, name from agents')]; \
print('MESSAGES:'); [print(' ', r) for r in con.execute('select id, agent_id, role, content from messages order by id')]"
```

Или откройте `day7/agents.db` любым SQLite-клиентом/расширением браузера.

## 5. FAQ и возможные проблемы

| Проблема | Решение |
| --- | --- |
| Фронтенд пишет «Бэкенд недоступен» | Запустите uvicorn (раздел 3) и нажмите «🔄 Обновить список». `requests` не ходит через браузер, CORS не при чём. |
| «Порт 8000 занят» | Остановите процесс или смените порт: `--port 8001` у uvicorn и `DAY7_BACKEND_URL=http://127.0.0.1:8001` у фронтенда. |
| Генерация: «Ключ API не задан» (502) | Создайте `day7/.env` или задайте `DEEPSEEK_API_KEY` (раздел 2). Ключ читается на каждый запрос — рестарт не нужен. |
| DeepSeek отвечает ошибкой/таймаутом | Проверьте сеть и лимиты аккаунта (429). Ошибка показана в UI; история не изменяется — повторная отправка безопасна. |
| Агент «забыл» системный промпт после правки | Системный промпт — конфигурация агента (таблица `agents`), меняется при создании; реплики диалога хранятся отдельно. |
| Очень длинный диалог упирается в лимит токенов DeepSeek | Очистите историю кнопкой «🧹 Очистить историю» или создайте нового агента. |
| `agents.db` появился в папке, это нормально? | Да, это БД приложения. Она в `.gitignore` (`*.db`) и в git не попадает. |
| `deepseek-reasoner` игнорирует температуру | Поведение провайдера: модель рассчитана на reasoning. Используйте `deepseek-chat`, если важна температура. |
