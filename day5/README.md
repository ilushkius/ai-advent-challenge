# День 5 · Сравнение трёх моделей Hugging Face

Исследовательское Streamlit-приложение: один и тот же запрос отправляется в
**три модели разного размера** через клиент `huggingface_hub`
(`InferenceClient.chat_completion` — OpenAI-совместимый формат), после чего
сравниваются **время ответа, токены, стоимость и качество** ответов.

## Какие модели сравниваются

| Роль | Модель | Размер |
|---|---|---|
| 🟢 слабая | `meta-llama/Llama-3.1-8B-Instruct` | 8B |
| 🟡 средняя | `meta-llama/Llama-3.3-70B-Instruct` | 70B |
| 🔴 сильная | `Qwen/Qwen3-235B-A22B-Instruct-2507` | 235B-A22B (MoE) |

> ⚠️ Репозитории **Llama** и **Qwen** закрыты лицензией на скачивание весов
> (gated), но через **Inference Providers** — роутер Hugging Face — они
> доступны по ключу `HF_TOKEN` без дополнительных действий. Если модель
> временно недоступна, приложение покажет ошибку для неё и продолжит с
> остальными.

## Установка

```bash
pip install -r requirements.txt   # streamlit, huggingface_hub
```

## Настройка ключа HF_TOKEN

Ключ берётся в порядке: **`day5/.env` → переменная окружения `HF_TOKEN` →
ручной ввод в боковой панели приложения**.

```bash
# Вариант 1: файл .env рядом с приложением
copy .env.example .env            # затем впишите свой ключ в .env

# Вариант 2: переменная окружения (PowerShell)
$env:HF_TOKEN = "hf_ваш_ключ"
```

Файлы `.env` в git не коммитятся — в репозитории только шаблон
`.env.example`.

## Запуск

```bash
# Из папки day5 (важно: .env ищется в текущей папке приложения)
cd day5
streamlit run app.py

# Либо готовым окружением дня 5 (PowerShell, из папки day5):
#   .venv\Scripts\streamlit run app.py
#   (.venv содержит streamlit 1.63 + huggingface_hub 1.30)
```

Кнопка «Сравнить модели» последовательно опрашивает все три модели,
показывает ответы и метрики, сравнительную таблицу и оценку качества.

## Отчёт day5/results.md

После прогона нажмите «Сохранить отчёт в results.md» — приложение запишет
файл `day5/results.md` рядом с `app.py` (с ответами, метриками, таблицей и
практическими рекомендациями). Файл можно перезаписывать новыми прогонами.

Файл `day5/results.md` создаётся при первом живом прогоне с реальным ключом
`HF_TOKEN`; до выполнения эксперимента в репозитории его нет.

## Ограничения и примечания

- Запросы идут через **Inference Providers** (роутер Hugging Face), который
  биллингует аккаунт HF. У бесплатных аккаунтов есть месячные включённые
  кредиты (~$0.10); когда они заканчиваются, API возвращает ошибку
  **402 Payment Required** — нужны кредиты или подписка PRO. Цену конкретного
  запроса API в ответе не отдаёт, поэтому в колонке «Стоимость» показывается
  «цена не сообщена».
- Замеренное время включает **«холодный старт»** серверного инференса (у
  больших моделей вроде Qwen3-235B он может быть заметным) — при повторном
  «тёплом» прогоне время обычно меньше.
- Возможны лимиты запросов (ошибка 429) — повторите прогон позже.
- Оценка качества 0–10 — **эвристический фильтр** по тексту ответа
  (количество предложений, ключевые понятия, наличие примера, обрыв ответа);
  финальное суждение о качестве — за человеком.
