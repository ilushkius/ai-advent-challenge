# День 5 · Сравнение трёх моделей Hugging Face

Исследовательское Streamlit-приложение: один и тот же запрос отправляется в
**три модели разного размера** через Hugging Face Inference API
(OpenAI-совместимый эндпоинт), после чего сравниваются **время ответа,
токены, стоимость и качество** ответов.

## Какие модели сравниваются

| Роль | Модель | Размер |
|---|---|---|
| 🟢 слабая | `google/gemma-2-2b-it` | 2B |
| 🟡 средняя | `meta-llama/Llama-3.1-8B-Instruct` | 8B |
| 🔴 сильная | `Qwen/Qwen2.5-72B-Instruct` | 72B |

> ⚠️ Модель Llama — **gated**: перед первым запуском её нужно открыть в
> профиле Hugging Face (страница модели → «Agree and access repository»), а
> ключ должен принадлежать аккаунту с доступом. Если доступ не открыт,
> приложение покажет ошибку для этой модели и продолжит с остальными.

## Установка

```bash
pip install -r requirements.txt   # streamlit, openai>=1.0.0
```

## Настройка ключа HF_TOKEN

Ключ берётся в порядке: **`day5/.env` → переменная окружения `HF_TOKEN` →
ручной ввод в боковой панели приложения**.

```bash
# Вариант 1: файл .env рядом с приложением
copy .env.example .env            # затем впишите свой ключ в .env

# Вариант 2: переменная окружения (PowerShell)
$env:HF_TOKEN = "hf_ваш_ключ"
```

Файлы `.env` в git не коммитятся — в репозитории только шаблон
`.env.example`.

## Запуск

```bash
# Из папки day5 (важно: .env ищется в текущей папке приложения)
cd day5
streamlit run app.py
```

Кнопка «Сравнить модели» последовательно опрашивает все три модели,
показывает ответы и метрики, сравнительную таблицу и оценку качества.

## Отчёт day5/results.md

После прогона нажмите «Сохранить отчёт в results.md» — приложение запишет
файл `day5/results.md` рядом с `app.py` (с ответами, метриками, таблицей и
практическими рекомендациями). Файл можно перезаписывать новыми прогонами.

Файл `day5/results.md` создаётся при первом живом прогоне с реальным ключом
`HF_TOKEN`; до выполнения эксперимента в репозитории его нет.

## Ограничения и примечания

- Бесплатный тариф Inference API **не возвращает цену** — в колонке
  «Стоимость» показывается «бесплатно» (биллинг отсутствует). Платные
  тарифы/Inference Providers настраиваются в аккаунте Hugging Face.
- Замеренное время включает **«холодный старт»** серверного инференса (для
  72B может быть заметным) — при повторном «тёплом» прогоне время обычно
  меньше.
- На бесплатном тарифе возможны лимиты запросов (ошибка 429) — повторите
  прогон позже.
- Оценка качества 0–10 — **эвристический фильтр** по тексту ответа
  (количество предложений, ключевые понятия, наличие примера, обрыв ответа);
  финальное суждение о качестве — за человеком.
