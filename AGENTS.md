# AGENTS.md — правила проекта ai-challenge

Практикум по LLM (DeepSeek, Hugging Face) и агентная система: память, FSM состояния
задачи, инварианты, MCP-клиент и флот серверов, планировщик, пайплайны, оркестрация,
индексация и оптимизация затрат. Обзор — [`README.md`](README.md); цели и раскладка
слоёв — [`docs/project-rules.md`](docs/project-rules.md).

- **Основная папка — `day21/`.** Вся разработка идёт там. Новые папки `dayN` не
  создаются: история фиксируется git-коммитами и тегами.
- **`day1`–`day20` — архив (снимки).** Не читать и не менять их при работе над
  днём; ссылки на них остаются рабочими.
- **Архитектурный этап.** Сложное задание без структуры DoD, шагов и рисков
  сначала проходит через [`ARCHITECT_PROMPT.md`](ARCHITECT_PROMPT.md) в отдельном
  чате с DeepSeek; структурированный план исполняется напрямую. Простые задачи
  (кнопка, текст, правка документации) — без планирования.
- **Тесты.** Быстрый прогон — `uv run pytest -m "not slow"` (~30 с), полный —
  `uv run pytest -m ""` (~70 с). Набор идёт параллельно (`pytest-xdist`, `-n auto`);
  медленные интеграционные и e2e-тесты помечены `slow` и по умолчанию
  пропускаются; новые медленные тесты помечать так же.
- **Документация описывает только текущее состояние** проекта: устаревшее
  удалять, не копировать из прошлых дней.
- **Фиксация дня:** `git commit` с описанием дня, затем `git tag dayN`; запись в
  [`CHANGELOG.md`](CHANGELOG.md) и документация дня — в том же коммите.
- **Проверки перед «готово»:** тесты дня, `python -m py_compile` изменённых файлов,
  лимиты строк (любой `.py` ≤ 400, `app.py` ≤ 100, `backend/api/main.py` ≤ 80),
  smoke-запуск без реальных запросов к API.

Маршрут целиком — [`WORKFLOW.md`](WORKFLOW.md); sticky-правила — [`RULES.md`](RULES.md);
процедуры — скиллы в [`.omp/skills/`](.omp/skills/); правила дня —
[`day21/AGENTS.md`](day21/AGENTS.md).
