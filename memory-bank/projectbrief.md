# Project Brief — AI-челлендж

> Foundation-документ: цель, аудитория и ключевые требования проекта.

## 1. Что это за проект

**Название:** `ai-challenge` (папка `C:\Users\ilushkius\ai-challenge`).

Персональный учебный «AI-челлендж»: автор каждый день выполняет одно небольшое
практическое задание по изучению больших языковых моделей (LLM) и промпт-инжиниринга
на реальном API **DeepSeek** (OpenAI-совместимый endpoint).

Результат каждого дня — изолированная, самодостаточная мини-программа в папке `dayN/`.

## 2. Цель проекта

Постепенно (день за днём) на практике освоить:
- работу с OpenAI-совместимым API DeepSeek (`chat.completions`);
- управление параметрами генерации: `temperature`, `max_tokens`, `stop`,
  `seed`, `response_format` (JSON-режим);
- техники промптинга: zero-shot, Chain-of-Thought, мета-промпт (Prompt-v-Prompt),
  Persona Prompting («консилиум экспертов»);
- инструменты демонстрации: консольный скрипт → Streamlit-приложения.

## 3. Для кого

- **Автор и единственный пользователь** — ilushkius (Windows, VS Code, Python 3.14).
- По косвенным признакам (вкладка «JSON для копирования — удобно для видео и
  документации», акцент на наглядные логи) демо готовятся в т.ч. для записи
  видео/портфолио.

## 4. Ключевые требования (выведены из кода)

1. Python 3.14, Windows. Минимум зависимостей (`requirements.txt` на каждый день).
2. Весь код, комментарии и UI — **на русском**, с обучающими пояснениями.
3. Каждый день — отдельная папка `dayN/` со своими `app.py`/скриптом,
   `requirements.txt`, `.env.example`; папки не зависят друг от друга.
4. API-ключ `DEEPSEEK_API_KEY` **никогда не попадает в git**: `.env` игнорируется,
   в репозитории только `.env.example`-шаблон.
5. Демо обязано показывать «сырой» запрос/параметры и метаданные ответа
   (`finish_reason`, usage, время) — это обучающий проект.
6. Преемственность дней: День 2 = управление форматом ответа; День 3 = стратегии
   рассуждения поверх настроек Дня 2.

## 5. Границы (вне scope)

- Нет БД, бэкенда, авторизации, деплоя, тестов, CI. Это не коммерческий продукт.
