## Важные паттерны и предпочтения (стиль автора)
- Один файл = одно приложение дня; «чистая» логика — в функциях, UI — в теле модуля.
- Параметры запроса собираются в единый dict для вызова и лога (не расходятся).
- Текст модели экранируется `html.escape` перед выводом через markdown.
- Промпты/хинты/подписи — константы-словари вверху файла; UI-тексты на русском.
- Комментарии — обучающие, объясняют «почему», а не только «что».

## Инсайты/грабли, подтверждённые кодом
- База DeepSeek — строго `https://api.deepseek.com` (без `api.` не работает).
- JSON-режим требует system-промпт + `response_format={"type":"json_object"}`.
- `deepseek-reasoner` может игнорировать `temperature`/`response_format`.
- `seed` при фиксированных прочих параметрах даёт детерминизм «символ в символ».
- Для двухэтапного мета-промпта нужен запас токенов на Шаге А (600).
- День 1 не хранит историю диалога — модель «не помнит» предыдущие реплики.
