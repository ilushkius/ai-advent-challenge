# RULES.md — sticky-правила проекта

Работаем в `day21/`; `day1`–`day20` — архив, не читать и не менять.
Новые папки `dayN` не создавать: история фиксируется коммитами и тегами.
Сложные задания проходят через `ARCHITECT_PROMPT.md` перед выполнением.
Тесты: `uv run pytest -m "not slow"` (быстро), полный — `uv run pytest -m ""`.
Документация описывает только текущее состояние проекта.
Фиксация дня: `git commit` + `git tag dayN`.
Всегда `read` вместо `cat`/`head`/`tail`, `grep`/`glob` вместо `bash grep`/`find`.
Тяжёлые задачи (индексация, сводки, пакетная обработка) — в непиковые часы DeepSeek или на локальную модель (Ollama).
Подробности — `AGENTS.md`, `WORKFLOW.md`, `docs/project-rules.md`.
